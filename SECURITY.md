# Security Policy

## Supported versions

This package is pre-1.0. Security fixes are made against the latest `0.x` minor release only.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/ktownkinley/netsuite-rest-php/security/advisories/new)
(the repository's **Security** tab → **Report a vulnerability**). Include a description of the
issue, the affected version, and steps to reproduce if possible.

Never include real NetSuite credentials, private keys, or access tokens in a report.
